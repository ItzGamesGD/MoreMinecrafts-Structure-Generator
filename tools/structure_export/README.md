# Structure export (MVP)

Converts mcbuild Sponge v3 `.schem` output into Minecraft structure template `.nbt` files laid out
for MoreMinecrafts-Beta (MMB): `data/<namespace>/structure/<path>.nbt`, loaded as `<namespace>:<path>`
by template pools (`single_pool_element.location`) and `/place template`.

```bash
uv sync --frozen --extra dev --project vendor/mcbuild        # once
PY="uv run --project vendor/mcbuild python"
$PY -m tools.structure_export convert exports/structures/ruined_watchtower.toml   # write .nbt + report
$PY -m tools.structure_export check   exports/structures/*.toml                   # reproducible + verified
$PY -m tools.structure_export mmb  exports/structures/ruined_watchtower.toml --mmb ../MoreMinecrafts-Beta \
    --expect-commit c9f7a4bf748a3f688c4a3f8103bc16ba789d9b50                      # read-only MMB check
$PY -m tools.structure_export live exports/structures/ruined_watchtower.toml --server-jar server.jar --java java25
```

## Verified formats

| | Source: mcbuild `.schem` | Target: 26.3 structure template |
|---|---|---|
| Evidence | `vendor/mcbuild/src/mcbuild/export/schem.py`, `artifacts/phase-3/final/final.schem` | vanilla `data/minecraft/structure/*.nbt` inside the 26.3 server jar; all 57 MMB templates at `c9f7a4b` |
| Root | unnamed gzip compound → `Schematic` (Sponge v3) | unnamed gzip compound `{DataVersion, size, palette, blocks, entities}` |
| DataVersion | 3953 (mcbuild hard-codes 1.21.1) | 5023 (26.3 `version.json` `world_version`) |
| Palette | `{"ns:id[k=v,...]": index}`; states may be partial | list of `{id, properties?}`, property values are strings (not legacy `Name`/`Properties`) |
| Blocks | varint indexes, order `x + z*Width + y*Width*Length` | `{pos: [x, y, z], state, nbt?}` |

## Rules

- **Target version comes from the server jar, not from relabelling.** `reference/minecraft-26.3.json` is
  generated by `reference/build_reference.py` from the official 26.3 server jar (sha1 pinned): the data
  generator's blocks report (ids, properties, values, default states), `version.json` (DataVersion) and
  `BlockEntityProbe.java` (blocks implementing `EntityBlock`). Every source state must exist in it. For
  example 1.21.1's `minecraft:chain` (26.3: `iron_chain`) is rejected, not renamed.
- **Properties the source omits are filled with the 26.3 default state**, which is what the game does with a
  partial state. Each fill is listed in the report (`defaulted_properties`). Defaulted connection properties
  (`north/east/south/west/up/down`, e.g. on walls) also produce a `warnings` entry: jigsaw world generation
  places pool elements with `knownShape = true` (`SinglePoolElement` in the 26.3 jar), so they stay unconnected.
- **Size and origin**: `expect.size` and `expect.offset` in the config must equal the schematic's
  `Width/Height/Length` and `Offset`; the template's origin is the schematic's minimum corner.
- **Air**: mcbuild writes every unbuilt cell as `minecraft:air`, so authored and filler air cannot be told
  apart. `options.air = "include"` keeps all of it (the template clears its box); `"omit"` drops it.
- **Reproducible**: the source file is sha256-pinned; blocks are sorted by position, palette entries numbered by
  first use, gzip `mtime=0`; the report has no timestamps. `check` rebuilds in memory and requires the committed
  bytes.
- **Independent verification**: `verify.py` re-reads the `.nbt` and the `.schem` with its own NBT/varint decoder
  (no nbtlib, no converter code) and compares every cell.

## Not supported yet (rejected with `UnsupportedFeature`, never dropped)

| Feature | Rejected where | Extension point |
|---|---|---|
| Jigsaw blocks | palette | `FEATURE_HANDLERS["jigsaw"]` in `convert.py` |
| Block entities (chests, barrels, beds, signs, spawners, ...; 191 blocks in 26.3) and `BlockEntities` data | palette / reader | `FEATURE_HANDLERS["block_entity"]` |
| `structure_void` | palette | `FEATURE_HANDLERS["structure_void"]` (omit the cell) |
| Entities | reader | — |
| Multi-piece structures | config (`[[pieces]]`) | one config per template today |
| Sponge v1/v2, biomes | reader | — |

## Live validation levels

- `live`: vanilla 26.3 dedicated server. Loads the template from a datapack, places it with
  `/place template ... strict` (knownShape, as in jigsaw worldgen), tests every cell with `execute if block`,
  and compares against a DataFixer probe (the source states in legacy layout at DataVersion 3953, upgraded by
  the game itself) with `execute if blocks ... all`.
- MMB runtime (Fabric + MoreMinecrafts mod) is not run by this tool. MMB world generation registration
  (template pool / structure / structure set) is out of scope until approved.
